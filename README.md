# HARU · 每天一点韩语

一个通过浏览器使用的韩语学习平台：以基础学习为主线，每天安排 1–2 句你喜欢的歌曲歌词，配合发音、跟读和 FSRS 间隔复习。默认练习歌曲是 TAEYANG 的《Wedding Dress》。

## 线上学习与同步

线上版本使用 Sites 私有部署，同一 ChatGPT 账号在手机、电脑上登录后，共享云端学习进度。请以成功发布后提供的网址为准。

- 学习历史按北京时间展示知识点、已完成课程、学过的歌词、复习评分和打卡；无需打卡才有记录。
- 新记录保存当时的内容，换歌后仍能回看。旧备份只展示已有标记，不推测逐句学习日期。复习保留最近 10,000 次明细，日汇总长期保留。
- 改动自动保存，另一台设备在打开页面、返回窗口或每 30 秒读取最新进度。离线改动保留在当前设备，联网后重试。
- 两台设备同时修改时不会自动覆盖；到学习设置选择保留哪一版，选择前会下载本机备份。
- 本地进度不会自动跨网址迁移：先在旧页面导出 JSON，再到线上学习设置恢复备份。
- 本地音频不上传，不参与同步；换设备后需重新选择文件。

## 明天在另一台电脑启动

先安装 **Node.js 24 LTS** 和 Git；不需要 Python、数据库或 API Key。Windows、macOS、Linux 使用相同命令：

```sh
git clone https://github.com/wohaidingdezhu/haru-korean.git
cd haru-korean
npm ci
npm run build:local
npm run dev
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。如端口 4173 已被占用：

```sh
npm run dev -- --port 4174
```

启动后浏览器打开 http://127.0.0.1:4174 。停服务用 Ctrl+C。

首次使用：

1. 在「今日学习」学习 4 个知识点，再做 8 道识读、含文字替代提示的听辨题。完成后可直接继续下一课。
2. 进入「歌曲工作台」即可做 4 组跟读热身，不需要先找文件。热身来自基础课程，记录会自动保存。需要逐句练歌时，可通过「导入 / 更换歌词」添加 TXT / LRC / SRT，每行一句。
3. 默认每天 2 句，可在首页右上角的学习设置中改为 1 句。
4. MV 按已保存来源自动加载，不自动出声；没有当前来源链接时自动使用另一可用来源。更换来源收在可选设置中，也可以点击链接打开原页面。
5. 带时间轴的歌词会自动选好当天片段，点击「播放今日片段」或「听这一句」即可。Bilibili 支持跳转到起点；精确停止、循环和变速支持 YouTube 或本地音频。手动 A–B 与本地文件在可选设置中，无时间轴时不猜测片段。
6. 到复习页按真实记忆情况选择「忘记了 / 有点难 / 记得 / 很熟悉」。

## 换电脑时带走学习进度

纯本地运行时，进度、导入的歌词和笔记保存在**当前浏览器**。线上版本使用账号云同步，两种方式均不会随 GitHub 同步。

- 旧电脑：首页底部「导出进度」，或学习设置「导出备份」。
- 新电脑：学习设置「恢复备份」，选择导出的 JSON 文件。
- 本地歌曲媒体不包含在备份中，需在新电脑重新选择。
- 尽量使用同一个本地地址；localhost 与 127.0.0.1 是不同的浏览器存储来源。

## 已实现

- 独立「学习笔记」专区：每节视频课可新建一篇，记录标题、视频链接 / 课程出处和正文。输入自动保存，支持搜索、继续编辑与确认后删除；沿用账号云同步和完整备份，与歌曲的逐句备注分开。当前支持文字，每篇最多 30,000 字、最多 200 篇，整个学习进度仍受云端 3 MB 限制。
- 笔记的「韩文跟读」从正文提取完整韩文片段，逐条使用设备上的韩语语音慢读；孤立字母需配完整示例音节。重复片段合并，每次最多显示 100 条。未安装韩语语音时会提示使用原视频或词典；发音标注是文字辅助，不代替原声。
- 独立知识库：8 个发音专题、12 个语法知识点、48 个常用词、24 条常用语句。支持中文 / 韩文搜索、分类浏览、例句朗读、相关语法和课程跳转。主动加入复习后会生成卡片并保存学习历史；浏览不会自动完成每日任务。

- 14 节原创起步小课：韩文字母、拼读、收音、连音、问候、介绍、基本句型与语序。每课有 4 个知识点、8 道练习及答错解释，另有 4 组跟读热身。这是**入门阶段**，不等同于完整的初级到高级课程。
- 每天 1–2 句新歌词；同一天刷新、修改句数不会不断追加新句。漏学后继续推进，不补一大堆新句。
- FSRS 复习卡；新学内容首先在次日到期，之后依据记忆评分安排复习。
- 「我的复习」可切换今日到期和全部卡片，按中文 / 韩文 / 笔记和来源查找。全部卡片支持先回想再显示答案的自由自测，主动记录后进入历史，保留原有到期时间，不替代正式复习。
- 知识库支持筛选已加入复习、尚未加入复习的内容，与分类和关键词组合使用。
- 错题本自动收集小课与巩固题的错误答案，保存题目、解释、次数和最近时间。可集中重练，答对后标记已巩固并记录历史，不代替整节课程。
- 到期复习评分支持撤销本次页面的最后一次评分，恢复原卡片安排和对应记录；离开复习页、刷新、跨天或收到其他设备的新进度后不再撤销。
- 普通每日任务、3 分钟轻量模式、学习天数记录。无歌词时以跟读热身作为当天练习；完整模式需完成 4 组，轻量模式需完成 1 组。已完成的旧打卡记录保持不变。
- 小课答题、巩固题和跟读支持中途继续；页面切换使用地址片段，刷新保留当前入口，支持浏览器前进 / 返回。
- 小课和今日巩固题答对后立即保存题目、正确答案与解释到历史，做几题后退出也有记录；同题同类练习在当天只记一次。回看知识点不会倒退续学位置，轻量模式保留完整测验的未完成进度。
- 标记歌词已学只更新进度，不重新加载正在使用的播放器。
- TXT / LRC / SRT 导入；时间轴字幕；本地媒体 A–B 循环和速度调整。
- JSON 进度备份 / 恢复、Anki TSV 卡片导出、SRT 导出。
- 桌面与手机布局；浏览器可用时提供韩语 TTS。

线上版本已支持账号云同步及学习历史；暂未实现自动歌词翻译、发音评分和定时提醒。YouTube/Bilibili 可用性仍取决于视频本身与访问网络；本地媒体练习不依赖这些服务。

## 开源项目如何复用

这是基于 **asbplayer 源代码的衍生学习入口**，具体复用方式如下：

- 完整上游源码快照保存在 `upstream/asbplayer/`，固定提交 `c8718d11f933f307088f2463c02e87a39cdc0571`，保留 AGPL-3.0-or-later 许可证。
- 运行代码直接导入上游的 `SubtitleCollection`，用于按音频时间显示字幕；直接导入 `subtitlesToSrt`，用于导出 SRT。这两个模块未修改。
- 中文学习界面、每日学习计划、课程、导入和进度管理是新增代码。没有内嵌完整的 asbplayer 浏览器扩展及原始 React 界面。
- FSRS 调度使用 [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)（MIT）。
- Anki 支持是 TSV 卡片导出接口；未复制 Anki 桌面客户端，也没有实时同步。

## 云端开发与发布

需要 Node.js 24。`npm run build` 生成 Sites Worker、静态学习页面与数据库迁移；`npm run dev:cloud` 启动带模拟登录的云端预览。访问 `/signin-with-chatgpt?return_to=/` 建立仅限本地开发的测试身份。`npm run db:generate` 生成迁移，使用 Sites 发布流程应用到线上数据库。数据库绑定为 `DB`，配置在 `.openai/hosting.json`。

纯本地学习继续使用 `npm run build:local` 与 `npm run dev`，不需要登录。

## 歌曲库

歌曲库支持添加、搜索、按学习状态筛选、切换、修改信息和删除。各首歌独立保存歌词、释义、学习进度、每日分配和播放片段。新增歌曲不会覆盖旧歌；所有歌曲共用每天的新句额度。删除前下载备份，学习历史与复习卡继续保留。

线上站点：https://haru-korean.xjj789789.chatgpt.site/ 。沿用现有 ChatGPT 登录，云端自动保存，无需另外注册账号。日常学习不需要手动备份。
